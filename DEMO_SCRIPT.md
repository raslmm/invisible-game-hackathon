# Demo recording plan — under two minutes

Target runtime: about 95 seconds. Record the local app in a clean browser window with no copyrighted music, third-party logos, or personal credentials visible. Keep the synthetic-data badge on screen.

| Time | Show and say |
| --- | --- |
| 0–10s | Open the app. “The Invisible Game turns synthetic match events into explainable, personalized match intelligence.” Point out the five-stage pipeline and synthetic-data badge. |
| 10–26s | Select `IGM002`, set replay speed to `240×`, and play. Show the pitch markers and live event count. “A busy turnover count does not automatically mean the defence is repeatedly exposed.” |
| 26–47s | Switch to `IGM001`, play at `240×`, and wait for the first on-screen story. Show the transient alert and then a later repeated-exposure alert. “The system separates one dangerous spell from a signal recurring across five-minute segments.” |
| 47–64s | Expand the workflow trace and click a cited event. Show its pitch marker and the evidence IDs. “The analyst stage can only use supplied events; the storyteller changes presentation, not the underlying measurements.” |
| 64–78s | Switch Analyst → Casual → Player Focus, choose a player, and show how the narrative changes. |
| 78–88s | Change language to Spanish. Keep the event IDs and metric chips in view to show the evidence remains the same. |
| 88–100s | Finish the replay. Show the recap, player highlights, synthetic-data note, and JSON export button. End on the project name and repository URL. |

## Recording checklist

- Keep the recording below 120 seconds; this plan is designed for roughly 100 seconds.
- Do not imply a real live broadcast connection or claim real-world model accuracy.
- State whether Azure AI Foundry is configured in the recording. The default local workflow works offline and is clearly labelled.
- Add the finished video to YouTube, Vimeo, Facebook Video, or Youku and place its public URL on the hackathon project page. The recording and upload remain submission-owner actions.
